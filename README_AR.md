# Football 3D — النسخة الأولية

دي أول نسخة لعب فعلية قابلة للتطوير، وليست لعبة نهائية بمستوى eFootball.

## الموجود حاليًا
- ملعب كرة قدم ثلاثي الأبعاد مع خطوط ومرميين.
- لاعب أخضر تتحكم فيه بعصا لمس.
- كرة لها حركة وارتداد واحتكاك مبسط.
- أزرار تمرير وتسديد.
- لاعبو خصم يتحركون باتجاه الكرة بشكل أولي.
- كاميرا متابعة من زاوية تلفزيونية مرتفعة.
- واجهة عربية مناسبة للموبايل.

## التشغيل
1. ارفع محتويات المجلد إلى مستودع GitHub جديد.
2. من Settings ثم Pages فعّل النشر من الفرع الرئيسي ومن مجلد root.
3. افتح رابط GitHub Pages من الهاتف. الأفضل تدوير الهاتف للوضع الأفقي.
4. يلزم اتصال إنترنت لتحميل مكتبة Three.js من CDN في هذه النسخة.

## التحكم
- العصا اليسرى: حركة اللاعب.
- تمرير: تمريرة قصيرة إذا كنت قريبًا من الكرة.
- تسديد: تسديدة أقوى.
- إعادة المباراة: إعادة الكرة واللاعب والنتيجة.

## خطة التطوير التالية
1. تحسين نموذج اللاعب والحركات والأنيميشن.
2. إضافة فريقين بتشكيل 11 لاعبًا وذكاء اصطناعي للتمركز والدفاع.
3. إضافة الاستحواذ والافتكاك والحارس والحكام.
4. تحسين المؤثرات والصوت والقوائم.
5. تغليف المشروع كتطبيق Android باستخدام Capacitor ثم بناء APK عبر بيئة بناء Android سحابية.

ملاحظة: هذه النسخة تعتمد على Three.js عبر CDN، ولذلك ليست Offline بالكامل بعد. سننقل المكتبة محليًا عند تجهيز نسخة التغليف.
